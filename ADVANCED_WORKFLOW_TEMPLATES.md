## 1. 🛍️ Multi-Style Product Showcase

**Problem Solved**: E-commerce brands need diverse product visuals for different platforms and audiences, but photoshoots are expensive and time-consuming.

**Solution**: Generate 5 distinct product photography styles from a single product image.

### Styles Generated:
1. **Minimalist Studio** - Clean, professional, white background
2. **Luxury Dark Mode** - Dramatic, premium, high-end aesthetic
3. **Natural Lifestyle** - Organic, relatable, Instagram-worthy
4. **Vibrant Pop Art** - Bold, colorful, social media optimized
5. **Futuristic Tech** - Sci-fi, innovative, cutting-edge

### Use Cases:
- E-commerce product listings (test which style converts best)
- Social media content variety
- Marketing campaigns across different demographics
- A/B testing visual styles
- Brand consistency exploration

### Credits: ~150 (30 per style × 5)

### Pro Tips:
- Start with a clean product photo on white background
- Add a lifestyle reference image for the Natural Lifestyle variant
- Disable styles you don't need to save credits
- Use results to identify which aesthetic resonates with your audience

## 2. 🎬 Viral Thumbnail Factory

**Problem Solved**: YouTube creators need attention-grabbing thumbnails that maximize click-through rates, but creating multiple variations is tedious.

**Solution**: Generate 4 emotion-driven thumbnail variations based on psychology principles.

### Emotions Generated:
1. **😱 Shock & Awe** - Dramatic, explosive, high-energy
2. **🤔 Curiosity Gap** - Mysterious, intriguing, suspenseful
3. **🎉 Pure Excitement** - Joyful, celebratory, positive
4. **⚡ Controversial Take** - Bold, polarizing, debate-worthy

### Psychology Behind Each:
- **Shock**: Triggers immediate attention through surprise
- **Curiosity**: Creates information gap viewers want to close
- **Excitement**: Positive emotions increase sharing
- **Controversy**: Polarization drives strong reactions

### Use Cases:
- YouTube video thumbnails
- A/B testing emotional appeals
- Maximizing click-through rates
- Content creator branding
- Viral content strategy

### Credits: ~120 (30 per emotion × 4)

### Pro Tips:
- Use a photo with neutral expression (AI transforms it)
- Add context image to ground thumbnail in video topic
- Shock & Curiosity work best for educational content
- Excitement excels for entertainment/lifestyle
- Use Controversy carefully to maintain trust

## 🎯 How to Use These Templates

### Step 1: Access Workflow Editor
1. Go to **Workflow** in the navbar
2. Click **Templates** in the sidebar
3. Select your desired template

### Step 2: Upload Your Assets
- Follow the node labels for what to upload
- All templates support drag-and-drop
- Optional nodes can be skipped

### Step 3: Customize (Optional)
- Edit prompt nodes to adjust style
- Change temperature for more/less creativity
- Disable nodes you don't need
- Adjust resolution/quality settings

### Step 4: Execute
- Click **Run Workflow** in the topbar
- Monitor progress in real-time
- Download results from output nodes

## 📊 Credit Management

### Estimating Costs
- Gemini Flash: ~10 credits per generation
- Banana Pro 2K: ~30 credits per generation
- Banana Pro 4K: ~50 credits per generation

### Optimization Strategies
1. **Test First**: Run with 1-2 variants before full workflow
2. **Disable Unused**: Turn off nodes you don't need
3. **Lower Resolution**: Use 1080p for testing, 2K for final
4. **Batch Similar**: Group similar projects together

## 🆘 Troubleshooting

### Template Won't Load
- Check browser console for errors
- Verify JSON syntax if customized
- Clear cache and reload

### Generation Fails
- Check credit balance
- Verify all required inputs provided
- Review prompt for invalid characters
- Check node connections

### Unexpected Results
- Adjust prompt temperature
- Add more specific keywords
- Try different reference images
- Experiment with style descriptors
